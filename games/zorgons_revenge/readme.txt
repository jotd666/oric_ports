Zorgon's Revenge remake by JOTD

Based on the 1983 oric game by John S Sinclair, IJK Software, sequel of Xenon 1.

features:

- pixel perfect rendering of the original game
- original algorithms used for enemy moves
- graphical enhancements (backgrounds)
- new sounds
- original music
- original bug fixes

options:

-d: double display
-e: enable enhanced gfx features (sets -d)
-f: full screen
-j: enable joystick
-m: enable original music

keys:

ESC: quit
ARROWS: move man left/right, move ship up/down
CONTROL: jump / fire
P: pause

joystick:

button 1: fire / jump
