L'Aigle d'Or (Golden Eagle) remake by JOTD/Hialmar

Based on the 1984 oric game by Louis-Marie ROCQUES, Loriciels.

Features:

- pixel perfect rendering of the original game & intro
- graphical enhancements (more than 8 colors)
- sampled sounds
- faster/more reactive
- in game save
- french/english language selection
- introduction included
- key redefinition

Options:

-s: simple display
-f: full screen
-n: skip intro

Keys (redefinable):

Q: suicide
A: sit
D: up/high jump
S: long jump
B: drink
G: climb
P: take
1: torch in hand
2: iron key in hand
3: gold key in hand
4: vial in hand
5: crowbar in hand
ARROWS: move
SPACE: stand

R: load game (new feature)
W: save game (new feature)

Notes:

- I played the original game recently and it appeared awfully slow and annoying,
  (although it is a good game I had completed without cheating in 1984). This version fixes that problem.
  
- The adaptation speeds up the game a lot. But monsters (bat, fireballs) and energy/torch decrease speed 
  have been compensated so the game is fast but not unplayable. Game is still hard because of the low
  money amount awarded that forces you to make choices and take risks at game start.

- I have added 10 savegame slots. Hardcore gamers should not use it but still it's tempting...
  Restoring a game sometimes isn't perfect. But it helps :)
